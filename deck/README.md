# Deck material

Screenshots and graphics for the SIH26152 presentation, all from the 28–30 Sep 2026 run on the collected data (3,677 messages, six platforms, all labelled, collection log intact).

- `ui/<page>.png` — 1440×900 crops of each dashboard page (30-day range, all sources); `ui/<page>-full.png` are the full-height captures.
- `graphics/pipeline.png` — how it works: six platforms in, one timeline, label and compute, console and API (2400×960).
- `graphics/terminal.png` — the backend working: a collection cycle, the tamper test, `eval --check` and `npm test`, the API from curl (2400×1240). Every line is real output.
- `graphics/eval.png` — labeller accuracy per dimension against dictionary and majority baselines (2200×1000).
- `src/*.html` — the graphics as HTML; render with headless Chrome at the sizes above.
